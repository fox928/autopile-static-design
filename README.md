# 🚗 Autopile – Auto Parts Website

A responsive front-end website for an auto parts platform, built using HTML5 and CSS3.

## 🌐 Live Demo

[View Live Website](https://fox928.github.io/autopile-static-design/)

## 🛠️ Technologies Used

- HTML5
- CSS3
- Responsive Web Design
- Flexbox

## ✨ Features

- Modern automotive-themed user interface
- Responsive page layouts
- Auto parts presentation
- Login page design
- Premium membership page design
- Multi-page navigation

## 📁 Project Structure

- `index.html` – Main homepage
- `style.css` – Main styling
- `assets/` – Images and graphics
- `login/` – Login page
- `premiumpge/` – Premium membership page

## 🎯 Project Purpose

This project was developed to practice front-end development skills, page structure, CSS styling, responsive layouts, and multi-page website design.

## 📝 Note

This is a front-end demonstration project. Authentication and premium membership functionality are not connected to a back-end service.
